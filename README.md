# Escala de Café

Aplicação front-end responsiva para montar a escala de café da equipe.

## Recursos

- Calendário mensal
- Tabela alternativa
- Mostra apenas um modo por vez
- Feriados automáticos do Brasil
- Feriados personalizados
- Arrastar e soltar no calendário
- Arrastar e soltar na tabela
- Clique no nome para trocar o responsável
- Exportação para PDF
- Exportação para Excel
- Salvamento no navegador com LocalStorage

## Feriados automáticos incluídos

- Confraternização Universal
- Tiradentes
- Dia do Trabalhador
- Independência do Brasil
- Nossa Senhora Aparecida
- Finados
- Proclamação da República
- Consciência Negra
- Natal
- Sexta-feira Santa
- Carnaval
- Corpus Christi

## Como usar

1. Abra o `index.html` no navegador.
2. Escolha ano, mês, participantes e feriados personalizados.
3. Clique em **Gerar escala**.
4. Use o modo **Calendário** ou **Tabela**.
5. Arraste e solte para reorganizar.

## Observação

As trocas manuais alteram a escala salva no navegador.
