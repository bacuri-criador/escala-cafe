Calendário ou tabela, com feriados automáticos, organização manual e exportação para PDF e Excel.

Configurações

Os feriados automáticos já entram no cálculo. Você pode adicionar feriados personalizados acima.

Modo de exibição

Mostramos só um modo por vez. O calendário é mais visual, a tabela facilita a troca manual.

Como editar

  • Arraste um nome para outro dia no calendário para trocar os responsáveis.
  • Na tabela, arraste uma linha para outra para trocar a escala.
  • Clique no nome de um dia útil para avançar para a próxima pessoa da lista.
